AJAYU juego 2d estilo pixel art
arquitectura que se usa para el desarrollo del proyectoe s programacion orinetada a objetos POO y patron de maquina de estados fsm

las tecnologias usadas son
Unity como motor grafico
el lenguaje que se usa es c#
el entrono donde se programa es visual estudio
y para el control de versiones y avances se usa github


Como descargar y ejecutar el proyecto
1. Clonar el repositorio ejecuntando el siguiente comando en la terminal:
   git clone y el url   que da github
   O descargar el proyecto en formato ZIP y descomprimirlo.
2. Abrir Unity Hub.
3. Hacer clic en el boton "Add" y seleccionar la carpeta del proyecto.
4. Seleccionar la version de Unity 6 (6000.0.40f1) para abrirlo.
5. Una vez dentro del editor, ir a la carpeta Assets/Scenes y abrir "SampleScene" para ejecutar el juego.
